# The Intracon Group website

A responsive, dependency-free static website for The Intracon Group Pty Ltd.

## Local preview

From this folder, run a local static web server and open the address it provides in a browser. For example:

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

- `index.html` — semantic single-page site content
- `styles.css` — responsive styling and visual system
- `script.js` — mobile menu, current year and subtle reveal effects
- `assets/intracon-logo.svg` — supplied Intracon logo
- `preview/desktop-home.png` and `preview/mobile-home.png` — local review captures

## Publishing status

This project is prepared for static hosting, including GitHub Pages, but has not been published. No custom-domain or DNS configuration is included. Add a `CNAME` file only when publication and the custom-domain change are separately approved.
